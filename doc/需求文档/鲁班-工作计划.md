# 鲁班（Luban）— AI 应用构建器 工作计划

> **项目名称**：鲁班 / Luban
> **定位**：从零新建的 AI Agent 驱动应用生成平台，提取原 Appsmith Inteli 项目核心能力，不做减法，只做重构
> **核心原则**：不碰原 Appsmith 项目代码，从零新建工程，选择性地把有用逻辑重构过去
> **技术栈**：前端 React 18 + TypeScript + Vite + Zustand，后端 Java 25 + Spring Boot 3 + Spring Data JPA + MySQL

---

## 前后端接口规范（API Contract）

> **设计原则**：去掉 Appsmith 原项目的 DSL/Layout/Widget/Git 分支/Theme/Plugin/CRUD 等低代码冗余字段，只保留 Inteli 应用核心链路。

### 通用约定

- **Base URL**：`http://localhost:8080/api/v1`
- **认证方式**：JWT Bearer Token，请求头 `Authorization: Bearer <token>`
- **统一响应格式**：
  ```json
  { "success": true, "data": <T>, "message": "ok" }
  // 或错误
  { "success": false, "data": null, "message": "错误描述" }
  ```
- **HTTP 状态码**：200 成功，201 创建成功，400 参数错误，401 未认证，403 无权限，404 不存在，500 服务端错误

## 启动方式（零配置，无需 hosts）

```bash
# 方式一：Docker 一键启动
docker-compose up

# 方式二：本地开发
# 终端 1 - 启动 MySQL
docker run -d --name luban-mysql -p 3306:3306 -e MYSQL_ROOT_PASSWORD=luban123 -e MYSQL_DATABASE=luban mysql:8.0

# 终端 2 - 启动后端（默认连接 localhost:3306，端口 8080）
cd backend && mvn spring-boot:run
# 输出：Tomcat started on port 8080

# 终端 3 - 启动前端（默认代理 /api → localhost:8080）
cd frontend && npm install && npm run dev
# 输出：http://localhost:5173
```

## 与 Appsmith 原项目的关键差异

| 差异点 | Appsmith 原项目 | 鲁班（新项目） |
|--------|----------------|---------------|
| **域名** | 强制 `dev.appsmith.com`，需配 `/etc/hosts` | 直接用 `localhost`，无需任何 hosts 配置 |
| **CORS** | 硬编码 `dev.appsmith.com` 白名单 | 开放 `localhost:5173`，配置简单 |
| **RTS 服务** | 独立 WebSocket 实时协作服务（`app/server/rts`） | **不需要**，去掉实时协作 |
| **后端模块** | 20+ Maven 子模块（interfaces/server/plugins/rts 等） | **单一 Maven 模块**，`mvn spring-boot:run` 即跑 |
| **数据库** | MongoDB（文档型） | **MySQL**（关系型），Spring Data JPA |
| **插件系统** | 动态加载 Java 插件（MySQL/PG/Mongo 等每种一个 jar） | 内联 JDBC 驱动，直接依赖 |
| **认证方式** | Cookie + Spring Security 复杂配置 | **JWT Bearer Token**，不依赖 Cookie 域名 |
| **启动方式** | 需分别启动 client + server + RTS，配 hosts | `docker-compose up` 一键启动，或前后端各一条命令 |
