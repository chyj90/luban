# Sprint 2：批量接入 + 安全加固

> **状态：🔴 待审阅** | **周期：3 周** | **目标：100 个接口 5 分钟导入，调用安全可控**

---

## 一、Sprint 目标

在 Sprint 1 MCP 底座的基础上，解决「规模化接入」和「安全可控」两个问题。

**关键验收标准：**

| # | 场景 | 操作 | 预期结果 |
|---|------|------|---------|
| 1 | OpenAPI 批量导入 | 上传 MES 系统的 OpenAPI 文档 | 一次导入 20+ 个 HTTP 工具，自动分组 |
| 2 | 批量工具启停 | 批量启用/禁用工具 | 分组一键操作，无需逐个点击 |
| 3 | HMAC 签名 | 配置 app_key + app_secret | 请求被伪造 → 签名验证失败 → 拒绝 |
| 4 | RBAC 权限控制 | 角色 A 的工具权限配置 | 角色 A 的 Agent 只能看到被授权的工具 |
| 5 | SSO 单点登录 | 配置 OAuth 2.0 | 通过企业账号登录鲁班 |

## 二、需求列表

### 2.1 OpenAPI 批量导入

**优先级：P0**

支持上传 OpenAPI/Swagger 文档，自动解析为工具定义。

**功能点：**

| # | 功能 | 说明 |
|---|------|------|
| 1 | 文件上传 | 支持 `.json` / `.yaml` 格式 |
| 2 | 路径解析 | 自动提取所有 API 路径为工具 |
| 3 | 参数 Schema 提取 | 自动提取请求参数 Schema（path/query/body） |
| 4 | 分组自动创建 | 根据 OpenAPI 的 tag 自动分组 |
| 5 | 预览确认 | 导入前预览所有工具，支持勾选/取消 |
| 6 | 冲突处理 | 已存在的工具名提示覆盖/跳过 |
| 7 | 批量配置 | 导入时设置组级默认配置（Base URL、鉴权） |

### 2.2 分组模板化配置

**优先级：P0**

支持分组级别的默认配置，工具创建时继承，减少重复配置。

**功能点：**

| # | 功能 | 说明 |
|---|------|------|
| 1 | 组级默认配置 | Base URL、鉴权类型、公共 Header |
| 2 | 配置继承 | 工具创建时自动继承组级配置 |
| 3 | 配置覆盖 | 单个工具可覆盖组级配置 |
| 4 | 模板变量 | 支持 `{{group.base_url}}` 等引用 |

### 2.3 API Key 安全增强

**优先级：P0**

| # | 功能 | 说明 |
|---|------|------|
| 1 | HMAC 签名 | app_key + app_secret + timestamp + nonce → 签名，防伪造 |
| 2 | 防重放攻击 | 请求携带 nonce + timestamp，服务端缓存 nonce，拒绝重复请求 |
| 3 | IP 白名单 | 限制 API Key 只能从指定 IP 调用 |
| 4 | 调用频率限制 | 每分钟/每小时 调用次数上限 |

### 2.4 RBAC 角色权限管理

**优先级：P0**

| # | 功能 | 说明 |
|---|------|------|
| 1 | 角色管理 | 创建/编辑/删除角色（如：设备工程师、生产主管） |
| 2 | 工具权限绑定 | 角色 → 工具权限（可调用哪些工具） |
| 3 | API Key 绑定角色 | 创建 API Key 时选择角色 |
| 4 | tools/list 权限过滤 | 根据角色只返回有权限的工具 |
| 5 | 数据级权限 | 同一工具不同角色返回不同数据范围（如：只能查本车间的设备） |

### 2.5 SSO 单点登录

**优先级：P1**

| # | 功能 | 说明 |
|---|------|------|
| 1 | OAuth 2.0 / OIDC | 对接企业 SSO（如 AD、飞书、钉钉） |
| 2 | 自动同步用户 | SSO 登录后自动创建/更新用户信息 |
| 3 | 与现有 JWT 共存 | SSO 登录后生成 JWT，后续请求沿用 JWT 认证 |

### 2.6 SQL 工具增强

**优先级：P1**

| # | 功能 | 说明 |
|---|------|------|
| 1 | 参数化查询模板 | 支持 `WHERE department = ${dept}` 参数替换 |
| 2 | 结果缓存 | 相同参数 5 分钟内返回缓存结果 |
| 3 | 多数据源支持 | 一个 SQL 工具可关联不同 Datasource |
