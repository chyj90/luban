# 常用异常排查指令

## CSS 样式调试 — Console 命令

### 1. 检查元素是否存在及尺寸
```js
const el = document.querySelector('.your-class');
console.log('元素:', el);
console.log('尺寸:', el?.getBoundingClientRect());
```

### 2. 检查 SVG 是否渲染
```js
const svg = document.querySelector('.your-class svg');
console.log('SVG元素:', svg);
console.log('SVG innerHTML:', svg?.innerHTML);
```

### 3. 查看元素 computed style（关键属性）
```js
const el = document.querySelector('.your-class');
if (el) {
  const cs = getComputedStyle(el);
  console.log('background:', cs.background);
  console.log('color:', cs.color);
  console.log('display:', cs.display);
  console.log('visibility:', cs.visibility);
  console.log('opacity:', cs.opacity);
  console.log('width:', cs.width);
  console.log('height:', cs.height);
  console.log('padding:', cs.padding);
}
```

### 4. 检查 SVG 渲染属性
```js
const svg = document.querySelector('.your-class svg');
if (svg) {
  const cs = getComputedStyle(svg);
  console.log('SVG stroke:', cs.stroke);
  console.log('SVG fill:', cs.fill);
  console.log('SVG display:', cs.display);
  console.log('SVG width/height:', cs.width, cs.height);
}
```

### 5. 检查全局样式是否影响元素
```js
// 检查全局 button 样式
console.log('全局button背景:', getComputedStyle(document.createElement('button')).background);
console.log('全局button color:', getComputedStyle(document.createElement('button')).color);
console.log('全局button padding:', getComputedStyle(document.createElement('button')).padding);
```

### 6. 查找所有匹配某 CSS 规则的样式来源
```js
// 在 Elements 面板选中元素后，在 Console 执行：
// 查看所有应用到该元素的样式规则
const el = $0; // $0 是当前 Elements 面板选中的元素
const sheets = document.styleSheets;
for (const sheet of sheets) {
  try {
    for (const rule of sheet.cssRules) {
      if (el.matches(rule.selectorText)) {
        console.log('来源:', sheet.href || 'inline', '选择器:', rule.selectorText, '规则:', rule.style.cssText);
      }
    }
  } catch(e) {}
}
```

### 7. 检查元素是否被 overflow hidden 裁剪
```js
const el = document.querySelector('.your-class');
let parent = el?.parentElement;
while (parent) {
  const cs = getComputedStyle(parent);
  if (cs.overflow === 'hidden' || cs.overflowX === 'hidden' || cs.overflowY === 'hidden') {
    console.log('overflow:hidden 父元素:', parent, parent.className);
  }
  parent = parent.parentElement;
}
```

## 常见 CSS 问题排查思路

1. **元素不可见** → 检查 `display`、`visibility`、`opacity`、`width/height` 是否为 0
2. **颜色不对** → 检查全局样式（如 `button { color: #fff }`）是否覆盖了组件样式
3. **尺寸不对** → 检查 `box-sizing: border-box` + `padding` 是否把内容区挤成 0
4. **SVG 不显示** → 检查 `stroke`/`fill` 是否被继承的颜色覆盖，检查 `width` 是否为 0
5. **hover 无效** → 检查全局伪类选择器（如 `button:hover`）是否被覆盖
