## 二、SSE 代理基础验证

### TC-SSE-01：SSE 事件格式与流式完整性

| 步骤 | 操作 | 预期结果 |
|:--:|------|------|
| 1 | 打开浏览器 DevTools → Network 面板，过滤 `dev/chat/stream` | 准备抓包 |
| 2 | 在开发助手输入：`请用 200 字介绍一下 ERP 系统的核心模块`，发送 | 请求发送到 `POST /api/v1/agent/dev/chat/stream` |
| 3 | 检查 Response Headers | `Content-Type: text/event-stream`，`X-Accel-Buffering: no` |
| 4 | 检查 Response Body（EventStream 标签页） | 事件按 `event:` + `data:` + 空行 格式排列，顺序为 delta → delta → ... → done |
| 5 | 检查每个 delta 事件 | `data` 字段包含 `{"content":"..."}` JSON，非空 |
| 6 | 检查 done 事件 | `data` 包含 `sessionId` 和 `messageId` 字段 |
| 7 | 观察前端流式输出 | 文本**逐字/逐词**出现，非一次性刷出，最后一句完整无截断 |
| 8 | 关闭 DevTools | — |
