## 二、前置准备

### 用例 0：准备基础数据

**目的**：创建行业、领域、概念、映射，为后续用例提供数据基础。

#### 0.1 创建行业

| 步骤 | 操作 |
|------|------|
| 1 | 进入行业管理页面（OntologyGroupPage） |
| 2 | 点击"新增行业" |
| 3 | 填写：名称=`manufacturing`，显示名称=`智能制造`，描述=`智能制造行业本体` |
| 4 | 保存 |

**预期结果**：行业创建成功，ID 记为 `${INDUSTRY_ID}`。

**验证**：
```sql
SELECT id, name, display_name FROM industry WHERE name = 'manufacturing';
```

#### 0.2 创建领域

| 步骤 | 操作 |
|------|------|
| 1 | 展开"智能制造"行业，点击"新增领域" |
| 2 | 填写：名称=`production_metrics`，显示名称=`生产指标`，行业=智能制造 |
| 3 | 保存 |

**预期结果**：领域创建成功，ID 记为 `${GROUP_ID}`。

**验证**：
```sql
SELECT id, name, display_name, industry_id FROM ontology_group WHERE name = 'production_metrics';
```

#### 0.3 创建概念

| 步骤 | 操作 |
|------|------|
| 1 | 进入概念编辑页面（ConceptEditorPage），选择领域"生产指标" |
| 2 | 点击"+ 新建概念"，依次创建以下概念 |

| 概念名 | 描述 |
|--------|------|
| `销售额` | 销售订单的金额总和 |
| `营收` | 企业总收入，包含销售收入和服务收入 |
| `产能利用率` | 实际产能占设计产能的比例 |
| `订单量` | 订单总数 |
| `客户` | 客户基本信息 |

**预期结果**：5 个概念创建成功，ID 分别记为 `${CONCEPT_SALES}`、`${CONCEPT_REVENUE}`、`${CONCEPT_CAPACITY}`、`${CONCEPT_ORDERS}`、`${CONCEPT_CUSTOMER}`。

**验证**：
```sql
SELECT id, name FROM concept WHERE group_id = ${GROUP_ID};
```

#### 0.4 创建概念映射

| 步骤 | 操作 |
|------|------|
| 1 | 在概念编辑页面，为"销售额"添加映射：`sales_orders.amount` |
| 2 | 为"营收"添加映射：`revenue.total_amount` |
| 3 | 为"产能利用率"添加映射：`production.capacity_rate` |
| 4 | 为"订单量"添加映射：`sales_orders.id`，聚合方式=`COUNT` |
| 5 | 为"客户"添加映射：`customers.name` |

**验证**：
```sql
SELECT c.name, cm.table_name, cm.column_name
FROM concept c JOIN concept_mapping cm ON c.id = cm.concept_id
WHERE c.group_id = ${GROUP_ID};
```

#### 0.5 创建概念关系

| 步骤 | 操作 |
|------|------|
| 1 | 在概念编辑页面，连接"营收"→"销售额"，关系类型=`COMPUTED_FROM` |
| 2 | 连接"营收"→"订单量"，关系类型=`CORRELATED` |

**验证**：
```sql
SELECT src.name AS source, tgt.name AS target, cr.relation_type
FROM concept_relation cr
JOIN concept src ON cr.source_concept_id = src.id
JOIN concept tgt ON cr.target_concept_id = tgt.id
WHERE src.group_id = ${GROUP_ID};
```

| FF-07 | 提交后数据库验证 | 上一步完成 | 1. 查询数据库 | `user_description` = 用户输入的文本，`pipeline_trace` 不为空，`conversation_history` 不为空，`feedback_type` = `'problem_feedback'`，`status` = `'pending'` |

**验证 SQL**：
```sql
SELECT id, feedback_type, status, user_description,
       pipeline_trace IS NOT NULL AS has_trace,
       conversation_history IS NOT NULL AS has_history,
       llm_analysis IS NULL AS no_llm_yet
FROM concept_feedback
WHERE session_id = '${SESSION_ID}'
ORDER BY created_at DESC LIMIT 1;
```

> **关键验证点**：`llm_analysis IS NULL` 必须为 `true`（提交时不触发 LLM，管理员查看时才触发）。
