# MES 制造执行系统 — 产品需求总览

## 1. 产品定位

面向离散/混合制造企业的云端制造执行系统（SaaS MES），覆盖 **计划排产 → 生产执行 → 质量管控 → 物料仓储 → 设备管理 → 数据分析** 全链路，实现生产现场信息的实时聚合、协作、分析与决策。

## 2. 目标客户

| 规模 | 人数 | 核心诉求 | 产品形态 |
|------|------|---------|---------|
| 小型工厂 | 20-150 人 | 透明化、防错、快速上线 | 軽量版（小工单级） |
| 中型工厂 | 100-2000 人 | 计划协同、质量追溯、效率提升 | 标准版（智造级） |
| 大型/集团 | 2000+ 人 | 多工厂协同、集团排产、供应链联动 | 企业版（供应链级） |

## 5. 核心设计原则

1. **云原生 SaaS**：多租户隔离、弹性伸缩、周级迭代发布
2. **移动端优先**：一线工人扫码操作，管理层移动看板
3. **数据实时流动**：工单数据在生产/质量/物料/设备间实时联动，无需人工传递
4. **低代码可配置**：工艺路线、检验标准、审批流、报表均支持配置化
5. **开放集成**：标准 REST API + Webhook，与 ERP/PLM/WMS 双向数据贯通

## 6. 全局数据约定

### 6.1 主键策略
- 所有表主键为 `id BIGINT AUTO_INCREMENT`
- 业务单据编号为系统生成（如 `WO202509050001`），不作为主键

### 6.2 审计字段
所有表包含以下审计字段，后续文档中不再重复：

| 字段 | 类型 | 说明 |
|------|------|------|
| created_at | DATETIME(3) | 创建时间，精度毫秒 |
| updated_at | DATETIME(3) | 最后更新时间 |
| created_by | VARCHAR(64) | 创建人用户ID |
| updated_by | VARCHAR(64) | 最后更新人用户ID |
| tenant_id | BIGINT | 租户ID，SaaS 隔离字段 |
| is_deleted | TINYINT | 逻辑删除标记 0=正常 1=已删除 |

### 6.3 枚举约定
- 状态字段统一使用 `VARCHAR(32)` 存储枚举字符串，不使用数字编码
- 枚举值全大写下划线分隔，如 `IN_PROGRESS`、`COMPLETED`

### 6.4 编号规则
| 单据类型 | 编号前缀 | 示例 | 规则 |
|----------|---------|------|------|
| 工单 | WO | WO202509050001 | 前缀+日期+4位流水 |
| 检验单 | QC | QC202509050001 | 同上 |
| 入库单 | GR | GR202509050001 | 同上 |
| 出库单 | GI | GI202509050001 | 同上 |
| 维修单 | MR | MR202509050001 | 同上 |
| 采购申请 | PR | PR202509050001 | 同上 |

## 7. 模块间核心数据流

```
  ERP(销售订单) ──→ 计划排产 ──→ 生产执行
                       │              │
                       │              ├──→ 质量管理(检验/判定)
                       │              │         │
                       ├──→ 物料仓储(齐套/领料) ←──┘
                       │              │
                       │              └──→ 设备管理(OEE采集)
                       │
                       └──→ 所有模块 ──→ 数据智能平台(看板/报表)
```

**关键联动规则：**
- 工单下达前必须通过物料齐套检查（物料仓储模块）
- 工序完工触发检验任务（质量管理模块）
- 检验合格才可流转至下工序（生产执行模块）
- 不良品判定触发隔离/返工流程（质量+生产联动）
- 设备故障停机自动挂起相关工单（设备+生产联动）
