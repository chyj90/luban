# 鲁班平台 用户手册

> 按角色组织。核心设计一句话：**业务用户永远只看到"更懂我的回答"，本体（概念、关系、口径）在幕后工作**——它让问数更准、口径统一，并在使用中自动进化，无需任何人"配置本体"。

## 1. 平台入口总览

顶栏五个一级入口（按权限可见）：

| 入口 | 谁用 | 干什么 |
|---|---|---|
| 工作中心 | 全体 | 待办审批、消费固化的数据页面 |
| 智能问数 | 全体 | 用自然语言问数，AI 出答案和图表 |
| 开发中心 | 应用开发者 | 搭建数据应用（页面/查询/流程） |
| 建模中心 | 口径管理员 / IT | 数据接入 + 语义运营 |
| 平台管理 | 平台管理员 | 人员、部门、角色、权限 |

## 2. 业务用户：智能问数与工作中心

### 2.1 问数（智能问数）

- **直接提问**：打开「智能问数」，像问同事一样提问。运营商语义包预置了典型问法：
  - "上月出账收入是多少？宽带和移动各占多少？"
  - "上月投诉量按投诉类型的分布？"
  - "唐山市路南区上月有多少投诉？"
  - 口语说法都能识别：营收=出账收入、客诉=投诉、携出/流失=离网、拉新=新增用户。
- **模板卡**：欢迎页「问指标 / 问异常」一键填入示例问题。
- **数据源范围**：页面顶部可选择限定某个数据源，默认全部。
- **看懂回答**：回答下方可展开「概念匹配过程」（口径从哪张表来、命中了哪些业务概念）。不需要看也能正常使用——它是给你核对口径用的。
- **对答案不满意**：用消息上的反馈入口标记"这个答案不对"，这是平台改进口径的重要信号，会被语义运营人员处理。
- **保存洞察**：有价值的分析可保存为洞察，供固化到工作页面。

### 2.2 工作中心

工作中心的页面由开发者提前固化（图表、报表、入口），打开即用，无需任何配置。问数中发现的分析结论经"洞察 → 开发固化"后出现在这里。

**业务用户不需要理解"概念/本体"是什么——问准了是应该的，问不准时标记一下，平台会变聪明。**

## 3. 应用开发者：开发中心

应用 owner 从应用中心进入开发中心（其他人看到的是应用使用页）。

- **两种建模方式**：左侧功能区手工编辑（页面 / 查询 / 流程 / 数据源 / 接口 / 设置），或打开对话泊坞窗与建模 agent 对话："建一个营收分析驾驶舱"。
- **概念语义优先**：建模 agent 会自动对齐平台统一口径——写查询前先匹配概念、按概念生成基准 SQL，表/列/JOIN 由映射保证，不会出现"两个页面两个数"。概念没覆盖的表才会裸建模；发现语义缺口时 agent 自动提交变更草稿给管理员审批，并在汇报里告知。
- **QueryEditor「从概念生成」**：手写查询时可直接搜索概念、按概念生成基准 SQL，与智能问数同一口径；搜不到概念会提示去建模中心补建。
- 查询写好后固化为应用页面 / 工作中心页面。

## 4. 口径管理员（语义运营）：建模中心

建模中心是语义的"运营驾驶舱"，菜单收敛为三组：

```
数据接入：系统管理 | 运行监控
语义运营：概念编辑器 | 绑定管理 | 问题洞察 | 语义包回归
凭据与模型：我的 KEY | 大模型配置
```

### 4.1 概念编辑器（语义的日常管理入口）

- **概念**：业务对象的统一口径（如"出账收入"= 月账单出账费用合计）。支持按类型（维度/指标/实体）管理，指标带默认聚合、单位、时间锚列。
- **概念域**：概念的分组授权单元。工具栏「+ 新建概念域」内联创建（原独立的概念域管理页已并入此处）。
- **映射**：概念 → 数据源表/列的绑定关系，是问数落表的依据。
- **变更审核**（超管）：所有自动/半自动产生的语义变更（问数中 AI 提议、建模 agent 缺口回流）汇总在此审批，批准后自动快照、热生效。

### 4.2 绑定管理（接新库的第一站）

选择数据源 → **自动绑定**（规则优先 + LLM 兜底）把现有概念批量映射到新库的表列 → 人工复核金额、状态枚举、时间字段。绑定集上还维护**方言词典**（口语说法 → 概念），问数 prompt 自动注入。

### 4.3 问题洞察（每周看一次的"缺口清单"）

自动从问数流量中挖出四类问题：**未命中概念 / SQL 失败 / 权限拒绝 / 用户标记的坏答案**。按聚簇展示高频说法，作为新增概念、补映射、补词典的依据。用户标记的坏答案也在这里处理。

### 4.4 语义包回归（改口径前后的安全网）

一键运行典型问题集（运营商语义包 8 用例 / 平台语义包 6 用例），结构化断言：概念命中、SQL 落表、回答可用性。**每次批量变更语义后跑一遍**，报告不达标不上线。

### 4.5 深链页面（不在菜单，排查用）

版本快照（`/modeling/concept-snapshots`，历史版本 diff 与回滚）、异步任务（`/modeling/concept-embeddings`，嵌入/自动匹配任务重试与标记）。

## 5. 平台管理员

- **人员与组织**：平台管理 → 用户 / 组织 / 角色；角色通过"概念域授权"控制可问的数据边界（如网格经理只能看本地市）。
- **数据源**：建模中心 → 系统管理接入业务库；运行监控查看连通性与调用状况。
- **审批流**：系统权限 / 工具权限 / 数据源权限审批在平台内流转，待办出现在工作中心。

## 6. 语义是怎么自己变聪明的

平台的语义底座有一条自动进化循环，各角色只承担一小步：

```
业务用户提问/标记 ──→ 系统自动识别缺口（问题洞察 + AI 提议 + 建模 agent 回流）
                          │
口径管理员审批（概念编辑器·变更审核）←── 全部变更进入待审队列
                          │
批准 → 自动快照 → 热生效 → 回归题集验证不打坏旧口径
                          │
                          └──→ 下一次提问直接命中
```

你不需要发起这个过程，只需要：**正常使用、不满意时标记、每周看一次问题洞察、变更后跑回归**。

## 7. FAQ

| 问题 | 回答 |
|---|---|
| 我需要先"配置本体"才能问数吗 | 不需要。运营商语义包已内置核心口径；问不准会被自动记录并进化 |
| "营收"和"出账收入"为什么是同一个数 | 平台统一口径（一个平台一套），方言词典把口语说法对齐到标准概念 |
| 为什么我查不了其他地市的数据 | 概念域权限按角色限制数据范围，请联系管理员 |
| 概念编辑器里找不到"概念域管理"页了 | 已并入概念编辑器：工具栏「+ 新建概念域」 |
| AI 提交的语义变更谁审批 | 超管在概念编辑器 → 变更审核面板处理，批准前不生效 |
| 换了数据库表名怎么办 | 绑定管理重新自动绑定即可，概念与口径不变 |
