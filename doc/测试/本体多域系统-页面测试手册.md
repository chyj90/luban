# 本体多域系统 - 电信行业端到端测试手册

> **场景设定**：某电信运营商（虚构：华夏电信）采购鲁班平台，需完成从系统初始化到日常问数的完整落地流程。
>
> **涉及角色**：
> - **超级管理员**（admin）：系统最高权限，负责平台基础配置、用户和角色管理
> - **本体管理员**（数据架构师，ontology_admin）：负责行业模板导入、本体建模、数据映射、语义索引
> - **业务分析员**（analyst）：日常使用问数功能进行电信业务数据查询
>
> **前置条件**：MySQL 已启动，已执行 `telecom-test-data.sql` 创建 5 个电信行业 Schema 及其数据。

---

## 前置准备：启动所有服务

| 序号 | 操作 | 验证 |
|------|------|------|
| P1 | MySQL 已启动，确认 `telecom_customer`、`telecom_product`、`telecom_billing`、`telecom_network`、`telecom_service` 五个库存在 | `SHOW DATABASES LIKE 'telecom_%';` 返回 5 行 |
| P2 | Python Embedding 服务已启动 | `cd embedding-service && python embedding_server.py` |
| P3 | Java 后端已启动 | `cd backend && mvn spring-boot:run` |
| P4 | 前端已启动 | `cd frontend && npm run dev` |
